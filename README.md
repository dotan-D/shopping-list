# קניות

אפליקציית PWA סטטית בעברית וב־RTL, מותאמת לטלפון. HTML, CSS ו־JavaScript בלבד, ללא תלויות וללא build.

## שימוש

1. בדף הבית בוחרים קטגוריה.
2. לוחצים על מוצר כדי להוסיף אותו, או מתחילים להקליד בשדה החיפוש ומקבלים השלמות מתוך הקטגוריה. אפשר לבחור בהשלמה במגע, או בחצים וב־Enter; Escape סוגר את ההשלמות. התוצאות מדורגות לפי התאמה לתחילת השם ולאחר מכן לפי שכיחות בקובץ המקור.
3. מוצר שכבר ברשימה מסומן ב־✓ ולא נוסף שוב.
4. להוספת מוצר שאינו בקטלוג, משתמשים ב״אחר״ בטקסט חופשי בכל קטגוריה או בקטגוריית ״אחר״ בדף הבית.
5. עוברים ל״הרשימה שלי״. סימון מוצר כנקנה מסיר אותו מיד מהרשימה. אפשר גם למחוק באמצעות הפח. בשני המקרים מופיע כפתור ״ביטול״, עד לפעולה הבאה על הרשימה, לשחזור הפריט האחרון שהוסר.

הרשימה נשמרת ב־localStorage במכשיר ובדפדפן הנוכחיים, ומסתנכרנת בין חלונות של אותו אתר בדפדפן. אין חשבון, שרת או סנכרון בין מכשירים. מחיקת נתוני האתר מוחקת גם את הרשימה. פריטים שטרם נקנו מהגרסה הקודמת נשמרים בגרסה החדשה; פריטים שסומנו בעבר כנקנו אינם מוצגים.

## קטלוג המוצרים

`catalog.js` מכיל 486 שמות מוצרים ייחודיים מתוך 487 שורות בקובץ `רשימת_מוצרים.xlsx`, בחלוקה ל־14 קטגוריות. הכפילות ״צ׳יפס קפוא״ אוחדה ושכיחויותיה חוברו. שמות המוצרים נשמרו כפי שסופקו, כולל כתיבים מקוריים; מספר ההופעות משמש לסידור לפי שכיחות. אין צורך בקובץ Excel בזמן הריצה. אפשר לערוך את שיוך הקטגוריות או להוסיף מוצרים ישירות בקטלוג, ללא build. ״סליים דליס״ הושאר ב״אחר״ משום שסוג המוצר אינו ברור.

## פיתוח מקומי

```sh
cd /workspace/shopping-list
python3 -m http.server 3000 --bind 0.0.0.0
```

Service Worker והתקנה למסך הבית דורשים HTTPS (או localhost בפיתוח). אחרי טעינה ראשונה והפעלת ה־Service Worker, הקטלוג, החיפוש והרשימה פועלים גם ללא רשת. ב־iPhone: Safari ← שיתוף ← הוספה למסך הבית.

## Vercel

ייבאו את המאגר ל־Vercel. `index.html` נמצא בשורש ואין צורך בפקודת build, בתיקיית פלט או במשתני סביבה. Vercel מגיש את הקבצים כאתר סטטי ב־HTTPS. אין צורך ב־`vercel.json`.

## בדיקות

בדקו בחירת קטגוריה, השלמה לפי הקלדה במגע ובמקלדת, הוספה חופשית, מניעת כפילויות, מעבר לרשימה, סימון כנקנה והסרה, ביטול ומחיקה. רעננו כדי לוודא שהרשימה נשמרה. אחרי הפעלת ה־Service Worker, עברו למצב Offline ורעננו; ודאו שהקטלוג, החיפוש והעריכה עדיין עובדים. בדקו ב־DevTools את ה־manifest ואת האייקונים.

```sh
node --check app.js
node --check catalog.js
node --check sw.js
```

בשינוי קובצי המעטפת או הקטלוג, עדכנו את גרסת המטמון ב־`sw.js`. גרסה חדשה של ה־Service Worker תופעל לאחר סגירת חלונות האתר הישנים ופתיחה מחדש.
